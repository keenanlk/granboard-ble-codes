# Security policy

## Supported versions

Only the latest release of the [`granboard`](https://www.npmjs.com/package/granboard) npm package gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/keenanlk/granboard-ble-codes/security/advisories/new) instead.

Include what's affected (the package, the demo, or an example), the steps to reproduce, and the impact you expect. You should get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Scope

In scope: the `granboard` package, the GitHub Pages demo, and the examples in this repo.

Out of scope: the GranBoard hardware, its firmware, and the official GranBoard app. Report problems with those to GranDarts.
