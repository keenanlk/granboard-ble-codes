Try your GranBoard in the browser

Connect over Bluetooth, throw a dart, and watch the hit come in. Every LED control shows the exact code and bytes the granboard package sends.

Chrome, Edge or Opera on desktop or Android
Connected GranBoard

This browser can't connect to Bluetooth devices

The demo needs Web Bluetooth, which works in Chrome, Edge and Opera on a computer or an Android phone. Safari and Firefox don't support it, and on iPhone and iPad every browser uses Safari's engine.

You can still click the board below to try it with simulated throws. Building an app? The package works with any BLE library, including React Native and Capacitor on iOS. Read the package docs.
